# Цифровой эквалайзер на основе МК семейства STM32F4
### Система способна в реальном времени обрабатывать входящий аудиосигнал в соответствии с заданными параметрами фильтрации.
## Обработка сигнала
* На вход система получает цифровой аудио сигнал.
* Фитрация происходит путем перемножения частотных характеристик сигнала и фильтра.
* Для получения частотной характеристики сигнала испольщуется FFT.
* Получение временной характеристики обработанного сигнала производится с помощью IFFT.
* Обработка сигнала ведется в реальном времени, в виду чего применятся двойная буферизация.
* Результат обработки подается на выходной интерфейс.
* Параметры фильтрации задаются внешними потенциометрами и цифровизуются внутренним АЦП.

## Параметры передачи
* Для передачи аудио сигнала используется интерфейс I2S.
    * Формат данных: Philips I2S 24 бит.
    * Частота дискретизации: 48 КГц.
    * Для увеличения быстродействия используется DMA.
